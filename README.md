# SwampFrog 🐸

Аркада про лягушку, которая вытягивает руки-«липучки» и ловит падающие фрукты,
уворачиваясь от мусора. Реализована на **Godot 4.7.2 (Mono) + C# (.NET 8)**,
в портретной ориентации (эталонное разрешение **540×960**).

## Игровой цикл

Игра имеет несколько состояний (`GameState` в `Game/Main.cs`):

| Состояние | Описание |
|---|---|
| `Menu` | стартовый экран: начать партию, мини-игра Suika, выход |
| `Playing` | классический режим ловли фруктов |
| `PerkSelect` | пауза с выбором перка (см. ниже) |
| `Suika` | мини-игра «фрукты в кувшине» |
| `GameOver` | итоги забега, рестарт/в меню |

Сложность растёт по мере набора очков: интервал спавна уменьшается
(0.95 → 0.34 сек), а скорость падения растёт (150 → 330 ед/сек).

---

## Управление

- **Зажать** палец/кнопку мыши — руки лягушки растут в сторону точки касания.
- **Вести** палец — менять направление рук прямо в полёте.
- **Отпустить** — руки втягиваются и доставляют пойманное лягушке.

Вся геометрия рук считается в «мировых» единицах, поэтому лягушка
дотягивается до любого угла экрана на любом разрешении.

## Объекты на поле

Каждый объект — `FallingItem`, тип задаётся перечислением `ItemType`:

| Тип | Что делает |
|---|---|
| `Fruit` | обычный фрукт (+10 очков, +1 XP, пополняет запас Suika) |
| `GoldenFruit` | золотой фрукт (+30 очков базово, +5 XP) |
| `Trash` | мусор — при касании рукой наносит урон |
| `Healing` | хилка (+1 жизнь), выпадает с малым шансом при неполном HP |

Виды фруктов — `FruitKind` и каталог `FruitCatalog`:
вишня, клубника, виноград, мандарин, яблоко, груша, персик, ананас, дыня, арбуз.
В классическом режиме активны первые 6 «мелких» фруктов; остальные
подключены в Suika.

---

## Очки, жизни и рекорд

- **Очки**: обычный фрукт `+10`, золотой `+30` (может меняться перками и комбо).
- **Жизни**: базово **3** (`MaxLives`), максимум можно увеличить перком «Панцирь» до 7.
- **Урон**: касание мусора или пропуск фрукта отнимает 1 жизнь.
- **Рекорд** (high score) сохраняется между запусками.

---

## Опыт и уровни

`XpSystem` (`Game/XpSystem.cs`) — чистая C#-модель опыта:

- обычный фрукт — **+1 XP**, золотой — **+5 XP**;
- **10 XP = 1 уровень**;
- максимальный уровень жабы — **50**.

Уровень виден в HUD (полоса опыта под счётом). Каждый 6-й уровень
открывает окно выбора перка.

## Система перков

Перки — это улучшения, выбираемые по ходу забега. Логика разнесена по файлам
в `Game/Perks/` и `Game/UI/`:

| Файл | Назначение |
|---|---|
| `PerkDefinition.cs` | `PerkId` + описание перка |
| `PerkCatalog.cs` | каталог всех перков (данные) |
| `PerkState.cs` | состояние забега: уровни перков, слоты, выбор |
| `PerkEffects.cs` | числовая механика всех эффектов |
| `PerkPlayer.cs` | рантайм-логика: таймеры, награды, взрывы |
| `UI/PerkSelectionOverlay.cs` | оверлей выбора из 3 карточек |

**Правила выбора:**
- выбор открывается **раз в 6 уровней** (уровни 6, 12, …, 48);
- на экране **3 случайных доступных перка**, выбрать можно **1**;
- за забег доступно максимум **8 улучшений** (слотов);
- игра ставится на паузу на время выбора.

Каждый перк имеет **3–5 уровней прокачки** — при повторном выборе того же
перка его уровень растёт на 1.

### Список перков

| Перк | Слоган | Эффекты (по уровням) |
|---|---|---|
| **Липкие ладони** | Фрукты прилипают | радиус ловли +30%/+60%/+90% → магнит 2 м → магнит 4 м + 2 фрукта в ладони |
| **Резиновый хват** | Отскок спасёт | +1 очко за фрукт → шанс отбросить мусор 15% → 30% |
| **Скорострельность** | Как пулемёт | вытягивание +20% → втягивание +20% → общая скорость +30%/+40%/+50% |
| **Зона замедления** | Фрукты в сиропе | падение −15%/−25% в нижней трети → −35% в половине → мусор сильнее → пауза 1 сек при золотом |
| **Золотая лихорадка** | Шанс на богатство | +5%…+20% шанс золотого, x5/x7/x10 очков, золотой медленнее, каждый 10-й — золотой |
| **Фруктовый взрыв** | Цепная реакция | +1 очко если рядом → взрыв 1 м → 2 м + бонус → уничтожает мусор → каскад |
| **Комбо-мастер** | Серии решают | комбо не сбрасывается → растёт быстрее → x3 вместо x2 → +1 HP каждые 10 → кап x10 |
| **Панцирь** | Жаба-черепаха | +1/+2/+3/+4 HP → неуязвимость 2 сек после урона |
| **Отбрасывание мусора** | Фу, гадость! | мусор отскакивает с шансом 10% → 20% → 30% |
| **Вторая жизнь** | Жаба-феникс | возрождение 1 раз (1 HP) → 1 раз (3 HP) → 2 раза → +2 сек неуязвимости → 3 раза + очистка экрана |
| **Язык-молния** | Жаба-электрик | авто-ловля раз в 30/20/10/5 сек, 2 фрукта, уничтожает мусор |
| **Взгляд василиска** | Застынь! | заморозка каждые 40/30/30/15 сек на 1–3 сек, мусор каменеет, замороженные дают x2 |

## Система комбо

Базовое комбо начисляется за каждую поимку:

- каждая поимка добавляет очки комбо;
- **промах сбрасывает комбо** (перк «Комбо-мастер» ур. 1 это отменяет);
- множитель очков растёт с комбо (базово **x2 за 10 комбо**, кап **x10**).

«Комбо-мастер» ускоряет набор комбо и поднимает множитель, а на 4-м уровне
каждые 10 очков комбо дают **+1 HP**.

## Мини-игра Suika

Мини-игра, в которой лягушка двигается по верхней границе экрана и бросает
фрукты в кувшин:

- фрукты используют тот же `FallingItem`, поэтому внешний вид всегда совпадает
  с основным режимом;
- два одинаковых фрукта при соприкосновении **сливаются** в более крупный вид;
- за слияние начисляются очки, ведётся **рекорд Suika**;
- пул фруктов берётся из **запаса**, накопленного в классическом режиме.

---

## Запас фруктов

Каждая поимка обычного фрукта в классическом режиме добавляет его в запас
(вид → количество). Запас:

- тратится на броски в **Suika**;
- сохраняется между партиями и перезапусками;
- кнопка «Мини-игра: Suika» активна только при непустом запасе.

---

## Сохранение

Все данные хранятся в `user://save.cfg`:

| Секция | Ключ | Значение |
|---|---|---|
| `score` | `high` | рекорд классического режима |
| `suika` | `high` | рекорд мини-игры |
| `collection` | `fruits` | запас фруктов в формате `Вид:Количество,...` |

## Архитектура и расширяемость

Функциональность разнесена по связанным файлам, чтобы её было легко дорабатывать:

```
Game/
├── Main.cs              — корень игры: фон, спавн, счёт, жизни, состояния
├── Frog.cs              — лягушка с вытягивающимися руками
├── FallingItem.cs       — падающий объект (фрукт/золото/мусор/хилка)
├── HUD.cs               — интерфейс: счёт, жизни, XP, оверлеи
├── SuikaGame.cs         — мини-игра Suika
├── XpSystem.cs          — модель опыта и уровней
├── FruitKind.cs         — перечисление видов фруктов
├── FruitCatalog.cs      — каталог фруктов (имя, радиус, активность)
├── ItemType.cs          — типы падающих объектов
├── Perks/
│   ├── PerkDefinition.cs
│   ├── PerkCatalog.cs
│   ├── PerkState.cs
│   ├── PerkEffects.cs
│   └── PerkPlayer.cs
└── UI/
    └── PerkSelectionOverlay.cs
```

### Как добавить новый перк

1. Добавить значение в `PerkId` (`PerkDefinition.cs`).
2. Добавить запись в `PerkCatalog` (имя, слоган, уровни эффектов, цвет).
3. Реализовать числовые эффекты в `PerkEffects`.
4. Подключить модификатор в игровом коде (`Main`/`PerkPlayer`) — обычно 2–3 строки.

UI и логика выбора перка при этом не меняются.

### Как добавить новый фрукт

1. Значение в `FruitKind`.
2. Запись в `FruitCatalog.All`.
3. Метод отрисовки в `FallingItem.DrawFruitByKind`.
Чтобы убрать фрукт с поля — поменять `ActiveInClassic` в `FruitCatalog`.

## Сборка и запуск

**Требования:**
- Godot **4.7.2 Mono** (C#);
- .NET **8.0** SDK.

**Запуск:**
1. Открыть проект в редакторе Godot и нажать Play, либо
2. собрать и запустить из командной строки:

```bash
dotnet build
godot --path .
```

Главная сцена — `Scenes/Main.tscn` (`res://Scenes/Main.tscn`).
