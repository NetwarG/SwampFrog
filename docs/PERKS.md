# Опыт, перки и субперки

← [Назад к README](../README.md)

## Опыт и уровни

`XpSystem` (`Game/Core/XpSystem.cs`) — чистая C#-модель опыта:

- обычный фрукт — **+1 XP**, золотой — **+5 XP**;
- **10 XP = 1 уровень**;
- максимальный уровень жабы — **50**.

Уровень виден в HUD (полоса опыта под счётом). Каждый 3-й уровень открывает окно выбора перка —
пока есть что предложить.

## Система перков

Перки — улучшения, выбираемые по ходу забега. Логика разнесена по файлам в `Game/Perks/`
и `Game/UI/Perks/`:

| Файл | Назначение |
|---|---|
| `PerkDefinition.cs` | `PerkId` + описание перка |
| `PerkCatalog.cs` | каталог перков: данные и загрузка иконок |
| `PerkState.cs` | состояние забега: уровни перков, лимит шести перков, выбор |
| `PerkEffects.cs` | числовая механика всех эффектов |
| `PerkPlayer.cs` | рантайм-логика: таймеры, награды, взрывы |
| `UI/Perks/PerkSelectionOverlay.cs` | оверлей выбора из 3 карточек (иконка слева, выбор удержанием) |
| `UI/Perks/HoldCardButton.cs` | карточка перка: иконка, текст и выбор удержанием 1 секунду |
| `UI/Perks/HoldProgressFill.cs` | заливка карточки слева направо — прогресс удержания |
| `UI/Perks/PerkBar.cs` | панель шести слотов: иконки перков и уровни внизу экрана |

**Правила выбора:**

- выбор открывается **раз в 3 уровня** (уровни 3, 6, …), пока есть что предложить;
- на экране **3 случайных доступных перка**, выбрать можно **1**;
- перк выбирается **удержанием**: короткий клик игнорируется, нужно зажать карточку на
  **1 секунду** (прогресс заполняет карточку слева направо светлым оттенком цвета перка);
- за забег можно взять не больше **6 разных перков** (`PerkState.MaxDistinctPerks`);
- пока взято меньше шести, в предложениях есть и новые перки, и уже выбранные — при повторном
  выборе уровень такого перка растёт;
- после шестого перка предлагаются **только эти шесть** (три случайных из тех, что ещё не на
  максимуме);
- лимита улучшений нет: взятые перки докачиваются до максимума;
- в окне выбора есть кнопка **«Реролл (N)»**: за забег даётся **базовый 1 реролл**, а улучшение
  «Реролл» добавляет ещё +1/+2; нажатие пересобирает предложение и тратит заряд (последний заряд —
  кнопка пропадает);
- когда все шесть перков на максимуме, окно выбора не открывается — новый уровень просто
  подсвечивается в HUD;
- игра ставится на паузу на время выбора.

Каждый перк имеет **3–5 уровней прокачки** — при повторном выборе уровень растёт на 1.

Внизу экрана отображается панель слотов перков (`UI/Perks/PerkBar.cs`): **шесть маленьких
квадратиков**. Занятый слот окрашен в акцентный цвет перка и показывает свою иконку, а в правом
нижнем углу — текущий уровень; на максимуме обводка становится золотой. Свободные слоты —
приглушённая рамка. Панель скрывается вместе с игровым HUD.

### Эффекты срабатывания

Моменты срабатывания перков рисуются кодом в мире (папка `Game/Effects/`) поверх предметов и под
HUD. Слою достаточно выпустить эффект: он сам тикает и удаляется по таймеру (0.22–0.8 сек),
поэтому «мусора» из узлов не остаётся. При рестарте, выходе в меню и Game Over слой очищается.

| Файл | Назначение |
|---|---|
| `EffectStyle.cs` | палитра эффектов и примитивы: кольцо, точка и ломаная с контуром |
| `EffectLayer.cs` | владелец эффектов: `SpawnShockwave`, `SpawnBolt`, `SpawnSparks`, `SpawnFlashWave`, `Clear` |
| `Shockwave.cs` | ударная волна: расширяющееся кольцо с гаснущим диском |
| `Bolt.cs` | ломаная молния от лягушки к цели со вспышкой в точке удара |
| `Sparks.cs` | разлёт искр с торможением и затуханием |
| `FlashWave.cs` | волна по всему полю: короткая заливка и расходящееся кольцо |
| `SlowZoneView.cs` | индикатор «Зоны замедления»: полоса с волнистой кромкой |
| `HandOverlayView.cs` | оверлей рук: след ладони, радиус ловли и радиус магнита |
| `ComboAuraView.cs` | аура комбо вокруг лягушки по множителю серии |

Каждое срабатывание дублируется в интерфейсе: квадратик перка в панели коротко подрастает и
вспыхивает белой обводкой (`PerkBar.Pulse` → `PerkIcon.StartPulse`). У таймерных перков по кромке
квадратика идёт дуга перезарядки: пустая сразу после срабатывания, полная — когда перк готов.
«Язык-молния» бьёт только по предметам, уже влетевшим в поле, поэтому разряд не тратится впустую.

Иконки перков — `Game/assets/perks/{IconName}.png` (512×512, прозрачный фон); имя файла задаёт
`PerkCatalog.IconName`.

| **Язык-молния** | Жаба-электрик | авто-ловля раз в 20/18/15/10 сек, 2 фрукта, уничтожает мусор |
| **Взгляд василиска** | Застынь! | заморозка каждые 30/25/20/12 сек на 1–3 сек, мусор каменеет, замороженные дают x2, спавн приостановлен |

Протухший фрукт считается **мусором** (см. [GAMEPLAY.md](GAMEPLAY.md)): перки, работающие с мусором —
«Отбрасывание мусора», «Резиновый хват», «Зона замедления», «Фруктовый взрыв», «Язык-молния»,
«Взгляд василиска» и очистка экрана «Второй жизни» — действуют на него так же.

## Субперки

Субперки — слабые накопительные модификаторы (1–5% за выдачу), которые выдаются весь забег и
тонко настраивают партию. У них нет максимального уровня и панели слотов, а выбор не показывается:
субперк выбирается **автоматически в фоне**, а список активных виден в окне паузы — **положительные
и отрицательные отдельными группами** (`Game/UI/Pause/SubPerkListView.cs`), каждая запись строкой
с уровнем и накопленным процентом.

Логика разнесена по файлам в `Game/SubPerks/`:

| Файл | Назначение |
|---|---|
| `SubPerkDefinition.cs` | `SubPerkId`, полярность и описание субперка |
| `SubPerkCatalog.cs` | каталог всех субперков (данные) |
| `SubPerkState.cs` | уровни, проценты, очередь выдачи и чередование полярности |
| `SubPerkEffects.cs` | числовая механика: проценты → множители |
| `SubPerkPlayer.cs` | рантайм-логика: автовыдача случайного субперка с роллом 1–5% |
| `UI/Pause/SubPerkListView.cs` | список активных субперков в окне паузы: положительные и отрицательные группами |

**Правила выдачи:**

- субперк выдаётся **весь забег**, максимального уровня нет;
- интервал между выдачами растёт от **2** до **10** уровней ступенями по 10 уровней жабы;
- уровни выдачи: **2, 4, 7, 10, 13, 17, 22, 28, 34, 43**;
- выдача **никогда не попадает на уровень основного перка** (кратный 3) — под-уровни и уровни не
  пересекаются;
- субперк выбирается **автоматически в фоне**: без оверлея и без паузы, поэтому «пропустить» его
  нельзя;
- каждый раз берётся **один случайный субперк текущей полярности**;
- полярность **строго чередуется**: первая выдача — положительная, вторая — отрицательная и т. д.;
- за выдачу субперк получает **случайный прирост 1–5%**;
- эффекты одного субперка накапливаются, вероятностные значения ограничены 100%.

### Список субперков

| Субперк | Полярность | Слоган | Эффект за взятие |
|---|---|---|---|
| **Мудрость** | положительный | Опыт капает | +1…5% к получаемому опыту |
| **Запасливость** | положительный | Мимо не пройдёт | +1…5% шанс, что фрукт попадёт в запас Suika дважды |
| **Витамины** | положительный | Здоровое питание | +1…5% к шансу выпадения хилки |
| **Чистота** | положительный | Меньше грязи | −1…5% к шансу выпадения мусора |
| **Азарт** | отрицательный | Больше риска — больше счёт | +1…5% к скорости спавна, утешение: +½% к очкам |
| **Голод** | отрицательный | Быстрее, вкуснее | +1…5% к скорости падения, утешение: +½% к очкам |
| **Теснота** | отрицательный | Всё валится | +1…5% к шансу выпадения мусора |
| **Бессонница** | отрицательный | Мысли путаются | −1…5% к получаемому опыту |

Положительные и отрицательные субперки работают парами по одной оси (опыт, хилка, мусор, запас,
спавн, падение), поэтому гасят друг друга.
