# Сохранение и локализация

← [Назад к README](../README.md)

## Сохранение

Все данные хранятся в `user://save.cfg`:

| Секция | Ключ | Значение |
|---|---|---|
| `score` | `high` | рекорд классического режима |
| `suika` | `high` | рекорд мини-игры |
| `collection` | `fruits` | запас фруктов в формате `Вид:Количество,...` |
| `meta` | `stats` | пожизненная статистика профиля: `runs:…,caught:…,golden:…,merges:…` |
| `audio` | `music` | громкость музыки от 0 до 1 (по умолчанию 1) |
| `audio` | `sfx` | громкость эффектов от 0 до 1 (по умолчанию 1) |
| `audio` | `muted` | полное отключение звука (по умолчанию выключено) |
| `locale` | `language` | язык интерфейса: `ru` или `en` (по умолчанию — по локали ОС) |

Старый ключ `audio/volume` из прежних сохранений переносится в `music` и `sfx`
(см. [AUDIO.md](AUDIO.md)).

## Локализация

Интерфейс и подписи данных (имена и эффекты перков, субперков, фруктов) переводятся на русский и
английский. Всё сосредоточено в `Game/Localization/`:

- `Language.cs` — перечисление языков;
- `Loc.cs` — точка доступа: `Loc.T(key[, args])` для строк интерфейса, `Loc.Pick(ru, en)` для строк,
  лежащих рядом с данными, `Loc.SetLanguage(...)`, `Loc.Current`, событие `Loc.Changed`;
- `LocKeys.cs` — константные ключи строк интерфейса (`L.*`);
- `LocText.Ru.cs` / `LocText.En.cs` — словари переводов.

Строки интерфейса лежат в словарях по ключу `L.*`, а переводы содержимого — прямо в каталогах: у
`FruitSpec`, `PerkDefinition` и `SubPerkDefinition` есть поля `...Ru` и `...En`, а свойства
`Name`/`Tagline`/`LevelEffects` выбирают нужный язык через `Loc.Pick`.

При первом запуске язык определяется по локали ОС (`ru*` → русский, иначе английский) и не
сохраняется, пока игрок не выберет язык. Кнопка-стикер `RU`/`EN` в левом верхнем углу главного меню
(`Game/UI/Hud/LanguageButton.cs`) переключает язык; выбор пишется в `user://save.cfg` (секция
`locale`), а открытые экраны обновляют подписи по событию `Loc.Changed` — без перезапуска.

**Как добавить строку интерфейса**: константа в `L`, запись в `LocText.Ru` и `LocText.En`.
**Как добавить перевод данных**: заполнить `...En` рядом с `...Ru` в соответствующем каталоге.
