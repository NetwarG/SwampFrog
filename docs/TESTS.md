# Тесты и проверки

← [Назад к README](../README.md)

Проверки лежат в `Tests/` (каталог исключён из Git, как и остальные локальные проверки) — это
headless-сцены на том же движке, что и сборка. Каждая — отдельный `.tscn`, который запускается так:

```bash
dotnet build
godot --headless --path . res://Tests/<Имя>.tscn --fixed-fps 60
```

Сцена печатает результат и завершается. Проверки не меняют сохранение игрока: исходный
`user://save.cfg` восстанавливается после прогона. Многие устроены как «замеры» — сцена измеряет
геометрию, физику или числа и падает, если значение вышло из ожидаемого диапазона.

## Что проверяет каждый сценарий

| Сценарий | Что проверяет |
|---|---|
| `FrogReachChecks` | вылет рук по пальцу: длина равна расстоянию от плеча до точки прицела, ладони и их хитбоксы стоят ровно в точке веера, разлёт ладоней растёт с вылетом (42 px на 200, 73 px на 350), плечи на боках тела, ограничение пределом поля, втягивание при пальце у лягушки, возврат по отпусканию |
| `FrogArmAttachChecks` | корни рук прикреплены к телу: плечи внутри непрозрачного силуэта во всех позах, руки вытягиваются и полностью втягиваются к телу; снимки `frog-arms-*.png` |
| `FrogArmSagChecks` | провис рук: на короткой руке нет, на средней изгиб 12 px, на длинной 28 px (предел 100 px); ладони остаются у пальца и в поле, предел длины упирается в кромку |
| `FrogBoundsChecks` | вертикальная полоса движения: тело в средней части поля (30–74%) на высотах 960/1200/2000, старт в полосе, отскоки и вертикальное движение, возврат тела из-за границ, пересчёт после ресайза |
| `DifficultyChecks` | модель сложности: рост по времени не изменился, квадратичный множитель от очков (×2 к 100 000, ×5 к 200 000), пол интервала спавна и потолок шанса мусора |
| `StockSaveChecks` | запас фруктов сразу меняется в памяти, запись объединяется таймером, `FlushPendingSave` пишет немедленно, исходный `save.cfg` восстанавливается |
| `HitboxChecks` | точная проверка силуэта сохраняет касание в центре, у кромки и после поворота; ограничивающий радиус покрывает все вершины фруктов и мусора |
| `SuikaPhysicsChecks` | физика кувшина: совпадение тела и силуэта (≤ 3 px), отклик горки на броски, отсутствие наложений |
| `SuikaFrogChecks` | посадка лягушки: низ тела над фруктом с зазором 0–20 px, центрирование, опускание вместе с кромкой на высоком поле |
| `SuikaHelpChecks` | кнопка «?» (64×64) и окно подсказки: цепочка из 10 фруктов, вписывание без уменьшения, блокировка бросков, закрытие по фону и «Понятно» |
| `SuikaMechanicsChecks` | механики Suika: разблокировка способностей по очкам (2000/3000/8000), заряды, детектор гироскопа и свайпа, тряска экрана, бомба (остановка и взрыв, смещение фруктов), уменьшение на 20% и предохранитель — фрукты остаются в кувшине |
| `SuikaVisualChecks` | снимки экрана Suika: фон и пустой кувшин, горка после бросков, высокое поле 1100 |
| `PauseChecks` | кнопка паузы в углу, выезд/сворачивание панели, остановка физики, спавна и таймеров, «Продолжить», список субперков группами по полярности, выход в меню без записи рекорда, системный «Назад» |
| `HudLayoutChecks` | счёт и жизни одной строкой слева, сердце перед числом, рост счёта и урон, запас до кнопки паузы; десять размеров экрана, SubViewport, попапы, границы лягушки, перенос стопки Suika |
| `ScreenCutoutChecks` | вырезы камеры: расчёты раскладки (без вырезов, у кромки, по центру, широкая «монобровь», повторный расчёт) и живой HUD — строка «Счет + жизни» уходит вправо от левого выреза, кнопка паузы влево от правого, без вырезов раскладка прежняя |
| `ButtonStyleChecks` | все кнопки — стикер с коричневым контуром и отдельным слоем фона; габариты иконочных кнопок |
| `IconAssetChecks` | сердце HUD, спрайт хилки и все 12 иконок перков — PNG 512×512 |
| `IconVisualChecks` | снимки главного экрана, окна выбора перков и панели слотов при ширине 540 и 320 |
| `SfxChecks` | голоса на шине `SFX`, непустые потоки банка, cooldown повторов, mute `Master` |
| `SoundChecks` | кнопка mute и рычажок в меню, шины `Music`/`SFX`, ползунки, запись громкостей и mute в `save.cfg` |
| `LocChecks` | совпадение ключей RU/EN, форматирование, имена перков и фруктов по языку, переключение по `RU`/`EN`, сохранение языка |
| `PerkEffectsChecks` | числа эффектов: интервалы «Языка-молнии» и «Взгляда василиска», «Зона замедления» 5-го уровня |
| `PerkSelectionChecks` | правила на `PerkState`: шесть разных перков за забег, сужение предложений, лимиты улучшений, закрытое окно на максимуме |
| `PerkFlowChecks` | живой сценарий: панель шести слотов, автовыдача субперка на 2-м уровне, окно выбора на 3-м, заливка карточки удержанием, счётчик в заголовке, базовый реролл и кнопка «Реролл» |
| `PerkVisualChecks` | эффекты срабатывания (волна, молния, искры, заморозка, аура, оверлей рук) и их самоочистка |
| `FreezeSpawnChecks` | заморозка поля останавливает спавн (предметы не копятся за кромкой) и после разморозки спавн возвращается |
| `MagnetChecks` | магнит «Липких ладоней»: не больше 6 притянутых фруктов на ладонь, берутся ближайшие, остальные падают как обычно |
| `FlyChecks` | мухи: полёт в границах поля, посадка на фрукт и порча, протухший фрукт как мусор (урон при касании, безопасный промах), поимка мухи ладонью (+25 очков) |
| `SubPerkEffectsChecks` | агрегация процентов по осям, ограничение шансов, диапазон прироста 1–5% |
| `SubPerkSelectionChecks` | правила на `SubPerkState`: уровни выдачи 2…43, чередование полярности, отсутствие пересечений с перками |
| `MetaStatsChecks` | модель статистики профиля: накопление счётчиков, строка сохранения и её разбор (мусор и отрицательные значения игнорируются) |
| `ProfileChecks` | ряд иконочных кнопок меню (профиль/магазин/Up), открытие статистики и галереи, Up неактивна, шрифт строк статистики, размер карточек улучшений, прокрутка списка колесом и свайпом с сохранением позиции, подписи плиток достижений вписаны в границы, сохранение игрока не меняется |
| `AdBannerChecks` | полоса рекламы в меню: место у нижней кромки экрана, кнопки меню и подпись авторов над ней, дом-баннер без SDK и по высоте полосы, скрытие в партии, освобождение места при выключенной рекламе |
| `RewardAdChecks` | кнопка рекламы с наградой: тот же размер и столбец, что у кнопки языка, открытие ролика, счётчик просмотра, +40 слизи и +30 случайных фруктов в запас только после досмотра, обновление бейджа, закрытие без награды по «Закрыть» и «Назад», отсутствие кнопки в партии и при выключенной рекламе |
| `WalletChecks` | кошелёк «Слизь»: начисление, списание, запрет минуса, событие изменения и формулы награды за забег и Suika |
| `SkinCatalogChecks` | данные скинов: слоты, доступность по рекорду, покупка за слизь, нормализация слота, загрузка иконок |
| `SkinApplyChecks` | слой шляпы и применение скинов, сохранение выбора, магазин: вкладки слотов и лента карточек |
| `HatAnchorChecks` | смещение шляпы по позам: idle без смещения, catching выше, angry ниже (за выступом глаз) |
| `UpgradeCatalogChecks` | каталог улучшений: уровни, растущие цены, иконки, капы игровых бонусов и базовый реролл |
| `UpgradeEffectChecks` | покупка уровней улучшений, списание слизи и сохранение в профиле |
| `AchievementChecks` | каталог достижений (пороги, награды, подписи, иконки), логика трекера и выдача награды ровно один раз |

## Снимки экрана

Без `--headless` часть сценариев дополнительно сохраняет PNG в `.godot/`:

- `ButtonStyleChecks` → `.godot/buttons-*.png`;
- `FrogArmAttachChecks` → `.godot/frog-arms-*.png`;
- `IconVisualChecks` → `.godot/icons-*.png`;
- `SuikaVisualChecks` → `.godot/suika-*.png`;
- `ScreenCutoutChecks` → `.godot/cutout-*.png`;
- `RewardAdChecks` → `.godot/reward-ad-*.png`;
- `PerkVisualChecks` → `.godot/effect-*.png`.

Для остальных снимков запустить без `--headless` и добавить `-- --screenshots`: изображения
сохранятся в `.godot/hud-*.png`, `.godot/menu-*.png` и `.godot/stock-*.png`.

Заполнение экрана полем, мобильный HUD и удобство управления дополнительно проверяются на эмуляторе
или устройстве.
