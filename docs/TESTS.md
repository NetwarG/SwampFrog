# Тесты и проверки

← [Назад к README](../README.md)

Проверки лежат в `Tests/` (каталог исключён из Git, как и остальные локальные проверки) — это
headless-сцены на том же движке, что и сборка. Каждая — отдельный `.tscn`, который запускается так:

```bash
dotnet build
godot --headless --path . res://Tests/<Имя>.tscn --fixed-fps 60
```

Сцена печатает результат и завершается. Проверки не меняют сохранение игрока: исходный
`user://save.cfg` восстанавливается после прогона. Многие устроены как «замеры» — сцена измеряет
геометрию, физику или числа и падает, если значение вышло из ожидаемого диапазона.

## Что проверяет каждый сценарий

| Сценарий | Что проверяет |
|---|---|
| `FrogReachChecks` | вылет рук по пальцу: длина равна расстоянию до пальца, ограничение пределом, втягивание при пальце у лягушки, возврат по отпусканию |
| `FrogArmSagChecks` | провис рук: на короткой руке нет, на средней ладонь опускается на 37 px, у пальца — 70/93 px (предел 100 px); ладонь и хитбокс остаются в поле |
| `SuikaPhysicsChecks` | физика кувшина: совпадение тела и силуэта (≤ 3 px), отклик горки на броски, отсутствие наложений |
| `SuikaFrogChecks` | посадка лягушки: низ тела над фруктом с зазором 0–20 px, центрирование, опускание вместе с кромкой на высоком поле |
| `SuikaHelpChecks` | кнопка «?» (64×64) и окно подсказки: цепочка из 10 фруктов, вписывание без уменьшения, блокировка бросков, закрытие по фону и «Понятно» |
| `SuikaVisualChecks` | снимки экрана Suika: фон и пустой кувшин, горка после бросков, высокое поле 1100 |
| `PauseChecks` | кнопка паузы в углу, выезд/сворачивание панели, остановка физики, спавна и таймеров, «Продолжить», выход в меню без записи рекорда, системный «Назад» |
| `HudLayoutChecks` | счёт и жизни одной строкой слева, сердце перед числом, рост счёта и урон, запас до кнопки паузы; десять размеров экрана, SubViewport, попапы, границы лягушки, перенос стопки Suika |
| `ButtonStyleChecks` | все кнопки — стикер с коричневым контуром и отдельным слоем фона; габариты иконочных кнопок |
| `IconAssetChecks` | сердце HUD, спрайт хилки и все 12 иконок перков — PNG 512×512 |
| `IconVisualChecks` | снимки главного экрана, окна выбора перков и панели слотов при ширине 540 и 320 |
| `SfxChecks` | голоса на шине `SFX`, непустые потоки банка, cooldown повторов, mute `Master` |
| `SoundChecks` | кнопка mute и рычажок в меню, шины `Music`/`SFX`, ползунки, запись громкостей и mute в `save.cfg` |
| `LocChecks` | совпадение ключей RU/EN, форматирование, имена перков и фруктов по языку, переключение по `RU`/`EN`, сохранение языка |
| `PerkEffectsChecks` | числа эффектов: интервалы «Языка-молнии» и «Взгляда василиска», «Зона замедления» 5-го уровня |
| `PerkSelectionChecks` | правила на `PerkState`: шесть разных перков за забег, сужение предложений, лимиты улучшений, закрытое окно на максимуме |
| `PerkFlowChecks` | живой сценарий: панель шести слотов, автовыдача субперка на 2-м уровне, окно выбора на 3-м, заливка карточки удержанием, счётчик в заголовке |
| `PerkVisualChecks` | эффекты срабатывания (волна, молния, искры, заморозка, аура, оверлей рук) и их самоочистка |
| `SubPerkEffectsChecks` | агрегация процентов по осям, ограничение шансов, диапазон прироста 1–5% |
| `SubPerkSelectionChecks` | правила на `SubPerkState`: уровни выдачи 2…43, чередование полярности, отсутствие пересечений с перками |

## Снимки экрана

Без `--headless` часть сценариев дополнительно сохраняет PNG в `.godot/`:

- `ButtonStyleChecks` → `.godot/buttons-*.png`;
- `IconVisualChecks` → `.godot/icons-*.png`;
- `SuikaVisualChecks` → `.godot/suika-*.png`;
- `PerkVisualChecks` → `.godot/effect-*.png`.

Для остальных снимков запустить без `--headless` и добавить `-- --screenshots`: изображения
сохранятся в `.godot/hud-*.png`, `.godot/menu-*.png` и `.godot/stock-*.png`.

Заполнение экрана полем, мобильный HUD и удобство управления дополнительно проверяются на эмуляторе
или устройстве.
