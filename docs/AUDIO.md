## Фоновая музыка

Оригинальная тема «Swamp Groove» звучит в меню, классическом режиме и Suika. Она запускается вместе
с `GameScreen`, не перезапускается при смене состояний и продолжает играть на игровой паузе.
Громкость плеера — −6 дБ, воспроизведение идёт на шине `Music`.

Тема записана в `Game/assets/audio/music/swamp_groove.wav`: 22 050 Гц, 16 бит, стерео, 24 такта при
112 BPM, длительность около 51,4 сек. Целостный цикл настраивает `Game/Audio/BackgroundMusic.cs`.
Маримба, бас, мягкие аккорды, свинговая перкуссия и «водяные» акценты синтезируются программно.

Для повторной генерации не нужны внешние библиотеки:

```powershell
python Tools/generate_music.py
```

Генератор детерминирован: повторный запуск создаёт тот же WAV-файл.

## Звуковые эффекты

Короткие эффекты озвучивают только значимые события и не спорят с музыкой: длительность
0,05–0,45 с, у каждого свой минимальный интервал между повторами, а питч слегка случаен. Пул из
двенадцати голосов ограничивает плотность, а общий mute (шина **`Master`**) глушит музыку и эффекты
сразу.

| Событие | Эффект | Особенность |
|---|---|---|
| Поимка фрукта | `catch.wav` | мягкая «капля», тише прочего |
| Поимка золотого | `golden.wav` | короткая искра из трёх нот |
| Хилка | `heal.wav` | две тёплые ноты вверх |
| Потеря жизни | `damage.wav` | глухой удар без резких частот |
| Отскок/распад мусора | `deflect.wav` | короткий «тик» |
| Новый уровень | `level_up.wav` | восходящие три ноты |
| Открылся выбор перка | `perk_offer.wav` | мягкий чайм |
| Перк выбран | `perk_pick.wav` | подтверждающий «тик» |
| Рост множителя комбо | `combo.wav` | питч растёт вместе с множителем |
| Конец игры | `game_over.wav` | нисходящая фраза |
| Бросок в Suika | `suika_throw.wav` | «плюх» |
| Слияние фруктов в Suika | `suika_merge.wav` | питч по уровню фрукта: лестница вверх |
| Кнопки меню | `ui_tap.wav` | очень тихий щелчок |

Звуки лежат в `Game/assets/audio/sfx/*.wav` (моно, 22 050 Гц, 16 бит). Для повторной генерации:

```powershell
python Tools/generate_sfx.py
```

Генератор детерминирован. Реализация: `Game/Audio/SfxPlayer.cs` (пул голосов, cooldown, случайный
питч), `Game/Audio/SoundBank.cs` (таблица эффектов), `Game/Audio/Sfx.cs` (точка вызова из игрового
кода), `Game/Audio/AudioBuses.cs` (шины `Music` и `SFX`).

## Управление звуком

Громкость и полное отключение звука задаются в правом верхнем углу **главного меню**; в партии,
Suika, на паузе и на экране итогов этих кнопок нет.

- **Кнопка mute** (иконка динамика) полностью включает и отключает звук: перечёркнутый динамик —
  тишина (шина **`Master`**).
- **Рычажок** слева от кнопки по тапу раскрывает и сворачивает **блок ползунков**; громкость он не
  меняет, а шеврон подсказывает направление: свёрнуто — вниз, раскрыто — вверх.
- **Два вертикальных ползунка** задают громкость перетаскиванием (0–100%): левый — **музыка**,
  правый — **эффекты**. Над каждым иконка: нота у музыки, динамик у эффектов; цвет заливки —
  зелёный у музыки, голубой у эффектов.
- Все они тоже кнопки-стикеры, а блок ползунков — тёмная панель с коричневым контуром.

Раздельные ползунки управляют шинами **`Music`** и **`SFX`**, которые обе посылают в **`Master`**,
поэтому mute глушит музыку и эффекты сразу. Громкости сохраняются в `user://save.cfg` (секция
`[audio]`) и применяются при следующем запуске ещё до старта музыки; старый ключ `volume` из прежних
сохранений переносится в обе шины.

Реализация: `Game/Audio/SoundSettings.cs` (шины и сохранение), `Game/Audio/AudioBuses.cs`,
`Game/UI/Sound/SoundControls.cs`, `SoundMuteButton.cs`, `SliderHandle.cs`, `VolumeSlider.cs`,
`VolumePanel.cs`, `VolumeIcon.cs`.
